# 3xui-mole

![3xui-mole](docs/assets/3xui-mole-banner.png)

[English](README.md)

3xui-mole управляет доступом по подписке к VPN-серверам с 3X-UI. Клиенты
пользуются веб-кабинетом или Telegram, а операторы управляют клиентами,
тарифами, платежами и поддержкой в одной системе. Оба интерфейса используют
общий backend и общие данные.

- **Клиентам:** регистрация, покупка и продление подписки, ссылки подключения,
  история платежей, рефералы, промокоды и поддержка.
- **Операторам:** согласование пробного доступа, управление подписками,
  каталог, разбор платежей, кампании, уведомления, статистика и аудит.
- **Администраторам:** управление серверами, деплой, настройка и резервные копии.

Поддерживаются ручные переводы, YooMoney, YooKassa, Cryptomus, Heleket и
Telegram Stars. Администратор отдельно включает каждый способ оплаты
и каналы Telegram.

| Документация | Руководство |
| --- | --- |
| Для операторов и администраторов | [Руководство пользователя](docs/operators.ru_RU.md) |
| Архитектура, деплой и конфигурация | [Инженерное руководство](docs/engineering.ru_RU.md) |

Backend написан на Go и использует PostgreSQL, Redis и фоновые задачи River.
Веб-приложение на React обслуживается через Caddy. Машиночитаемый
[контракт API](docs/api/openapi.yaml) хранится рядом с исходным кодом.

Этот проект вдохновлён [3xui-shop](https://github.com/snoups/3xui-shop).
